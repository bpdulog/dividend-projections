# Dividend Return Projections

A static GitHub Pages version of the dividend return workbook. It recreates the spreadsheet's monthly and quarterly projection logic with live controls, a chart, yearly rollups, CSV export, and saved preferences through `localStorage`.

## Run Locally

Open `index.html` in a browser, or serve the folder with any static file server.

## GitHub Pages

Publish this repository with Pages set to deploy from the root of the default branch. No build step is required.
